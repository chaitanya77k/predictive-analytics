# Predictive Analytics Using Historical Data

## Project Overview
This project predicts future sales using historical sales data and Linear Regression machine learning algorithm.

## Tools Used
- Python
- Google Colab
- Pandas
- Matplotlib
- Scikit-learn

## Dataset
Monthly sales dataset stored in CSV format.

## Features
- Data loading
- Predictive analytics
- Future sales prediction
- Graph visualization
- Accuracy checking

## Machine Learning Model
Linear Regression

## Output
The model predicts future sales trends successfully with good accuracy.

## Conclusion
Predictive analytics helps businesses forecast future trends using historical data.
